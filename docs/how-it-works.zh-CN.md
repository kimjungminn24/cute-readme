## 点阵主题的文字

`pixel` 不用 `<text>`，而是**把文字画成点阵**。任何文字的描述在任何地方都是点阵。

通过 `<img>` 载入的 SVG **只能用观看者电脑上装了的字体**。中日韩像素字体大多数人没装，只写字体名的话，仓库名是点阵、描述却掉回普通宋体。所以把链接徽章对拉丁字母用的办法（把字画成图形）扩展到了全角文字。

字形位图放在 [assets/galmuri11.dot](../assets/galmuri11.dot)：从 [Galmuri11](https://github.com/quiple/galmuri)（SIL OFL 1.1）的 BDF 中只挑出谚文音节、ASCII 和字母烤成的 340KB blob。工作流和编辑器读取它并通过 `renderRepoCard(repo, { dots })` 传入。**读不到也照样出卡片**，会安静地退回 `<text>`。

含有字体里没有的字（汉字、emoji）的那一行，整行用 `<text>` 画。混用的话同一行里字高不一致，反而更别扭。

> 因为文字是图形，SVG 正文里不会留下文本。取而代之的是 `<title>` 和 `aria-label` 里写着 `owner/repo`，读屏软件和搜索仍然能读到。

要重新烤这个 blob，从[发布页](https://github.com/quiple/galmuri/tree/main/dist)下载 `Galmuri11.bdf`：

```bash
node scripts/build-dotfont.js Galmuri11.bdf assets/galmuri11.dot
```

不存在的仓库、或者不是 `owner/repo` 格式的条目会被跳过，其余卡片照常更新。如果根本没有 `cards.json`，工作流什么也不做直接结束。

已迁移的仓库会按**当前地址**绘制（写 `facebook/react`，卡片和链接会显示成 `react/react`），因为 GitHub API 会通过重定向告知。

在本地预览：

```bash
npm run render:cards -- cards.json cards
```
## 谁能拿到大球

排名由 GitHub 给。`GET /repos/{owner}/{repo}/contributors` 返回的就是**按提交数降序排好的列表**，每一项都带着 `login`、`avatar_url` 和 `contributions`（提交数）。

大小是把那个提交数**用对数压平**之后定的。如果按原值成比例，500 次提交旁边的 20 次就是 0.04，除了第一名全都会落到最小档。老仓库基本都长这样，罐子里就只剩一堆小米粒。取对数之后 20 次提交能坐到中间位置，差距还在，画面也成立了。

**排名再给它设上限。**第二名不管提交多少，最多到比第一名低两级，第三名最多低三级。第一第二提交数差不多的仓库很常见（`facebook/react` 就是），最大的球有两个的话，原作的阶梯就塌了，罐子也跟着变长。提交少的仍然会掉到上限以下：第二名只有第一名的 1/400，那还是个小球。

机器人账号（`dependabot[bot]` 之类）会剔掉。它们的提交数把人类压得死死的，一个就能把罐子填满。

头像是**以 base64 烤进 SVG 里的。**通过 `<img>` 进入 README 的 SVG 取不到外部资源，只写地址的话每个球都会是空圆。没取到头像的人，用 ID 的首字母顶替。

预览和 `npm run preview:suika` 的示例用的是**不含真人的图形头像**（`sampleAvatar`）。它和 GitHub 给没设头像的账号配的花纹是一样的，颜色按黄金角旋转，好让相邻的两个尽量拉开。没有理由把陌生人的脸烤进示例里。想看真实照片是怎么裁的，跑 `npm run preview:suika -- owner/repo`。

## 堆叠的形状怎么来的

**物理只在画的时候跑一次。**通过 `<img>` 进 README 的 SVG 脚本是死的，没法在浏览器里模拟。于是改成在 Node 里从大到小一个个落下，把算出来的坐标烤进 SVG，**只有"掉下来"这个动作用 CSS 动画装样子。**

只是直直地落下的话，球会卡在别人肩膀上定住，看起来不像堆起来的，像贴上去的。所以落到别的球上的球会**顺着斜面滚**，直到两处触碰或者坐到底为止。

摆放的种子**只从贡献者列表里取**。用随机数的话，每天跑的工作流会把提交数根本没变、只是坐标抖了一下的 SVG 重新提交一次。主题不混进种子，混进去的话，选主题就变成重新摇一次摆放了。

## 唱机为什么不转

房间里的唱机是等距视角，唱片是斜着的椭圆。用点阵画的椭圆一转，锯齿边也跟着转，会很脏。所以唱片不动，只用 `scaleX` 让标签翻四帧，和地球仪只转大陆是同一个办法。
